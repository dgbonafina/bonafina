# Currículum Vitae

Este repositorio contiene una página de currículum vitae estático.

## Cómo abrir la página

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador web favorito. Puedes hacerlo de las siguientes maneras:
   - Haciendo doble clic sobre el archivo.
   - Ejecutando un comando similar a `xdg-open index.html` (Linux), `open index.html` (macOS) o `start index.html` (Windows) desde la terminal o línea de comandos.

Al abrirlo podrás ver la información del currículum de manera local sin necesidad de un servidor.
